# HR-Analytics-Dashboard---Excel-Tableau-Power-Bi
Power BI | Tableau | Excel | DAX | Data Visualization
Project Overview

Developed an interactive HR Analytics Dashboard using Power BI, Tableau, and Excel to analyze workforce trends, employee attrition, and performance metrics for an organization of 1,470 employees. The dashboard provides data-driven insights into employee demographics, attrition patterns, job satisfaction, and departmental performance through dynamic KPI visualizations and drill-down reporting.

Key Highlights
Analyzed workforce data for 1,470 employees and identified 237 attritions with an overall 16% attrition rate.
Built interactive dashboards to monitor:
Employee Count
Attrition Count & Attrition Rate
Active Employees
Average Employee Age
Department-wise Attrition
Job Satisfaction Ratings
Performed detailed attrition analysis across:
Departments
Age Groups
Gender
Education Fields
Job Roles
Used DAX measures, KPI cards, charts, slicers, and drill-down analysis to generate actionable HR insights.
Business Impact
Enabled HR teams to identify high-risk departments, job roles, and employee age groups with higher attrition trends.
Improved workforce planning and retention analysis through interactive and automated reporting dashboards.
Reduced manual reporting effort by transforming raw Excel-based HR data into real-time visual analytics.
Supported data-driven decision-making by highlighting key workforce and employee satisfaction trends.
